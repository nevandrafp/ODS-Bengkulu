# icon_website/

Favicon & ikon website (bukan logo Bank Mandiri — ini ikon tab
browser/PWA). Berisi placeholder generik yang dibuat otomatis:

- `favicon.png` (64×64) — dipakai `index.html` lewat tag `<link rel="icon">`
- `icon-192.png`, `icon-512.png` — cadangan untuk kebutuhan PWA/manifest jika
  suatu saat ditambahkan

Silakan timpa dengan ikon resmi Anda (nama file sama agar tidak perlu ubah
`index.html`).
