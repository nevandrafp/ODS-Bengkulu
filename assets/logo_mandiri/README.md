# logo_mandiri/

Letakkan logo resmi Bank Mandiri di sini dengan nama file:

```
logo-mandiri.png
```

`index.html` sudah menunjuk ke `assets/logo_mandiri/logo-mandiri.png` di
sidebar. Selama file ini belum ada, sidebar otomatis menampilkan mark
sederhana pengganti (fallback bawaan) supaya tampilan tidak rusak.

Catatan: logo Bank Mandiri adalah aset resmi/merek dagang milik PT Bank
Mandiri (Persero) Tbk — gunakan hanya file logo resmi yang sudah Anda
miliki izin penggunaannya (mis. dari brand guideline internal), bukan hasil
unduhan sembarangan.

Rekomendasi ukuran: tinggi ±48–64px, format PNG transparan.
